# AZLearn-Zig

Learn Zig through structured lessons, practical exercises, and projects.

## About

AZLearn-Zig is Akylos's personal Zig learning and practice repository.

## Environment

- Language: Zig
- Version: 0.17.1
- Platform: macOS Apple Silicon

## Structure

- src/ - Application source code
- lessons/ - Zig learning lessons
- projects/ - Practical projects
- notes/ - Learning notes
- tests/ - Tests

## Build and Test

- zig build
- zig build run
- zig build test
